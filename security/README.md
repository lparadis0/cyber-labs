# Security Labs

Hands-on security labs focused on Linux hardening, access control, monitoring and defensive security fundamentals.

## Lab Areas

- User permissions and access control
- File permissions and ownership
- UFW firewall configuration
- SSH security basics
- Log inspection and monitoring
- Fail2ban basics
- Linux system hardening basics
- Basic incident response workflows

## What This Demonstrates

- Security-first mindset
- Understanding of defensive security fundamentals
- Practical Linux security skills
- Monitoring and hardening awareness
- Readiness for IT support, operations and junior security roles
