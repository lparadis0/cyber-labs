# Linux Basic Commands Lab

This lab contains basic Linux commands used for navigation, file management and system interaction.

## Navigation

pwd
ls
cd
cd ..

## File Management

touch file.txt
mkdir test_folder
rm file.txt
rm -r test_folder

## Viewing Files

cat file.txt
less file.txt
head file.txt
tail file.txt

## Permissions

chmod +x script.sh
ls -l

## Process

ps
top

## Notes

All commands tested on Linux environment.
